Clinical Case Review: Domain Model

Types live in src/domain/. Orange = optional field, blue = reference to another entity.

Aggregate: a case and everything it owns

PatientCase root

case.ts
  • id string
  • patient Patient
  • status CaseStatus
  • priority CasePriority
  • updatedAt ISO string
  • symptoms string[]
  • labResults LabResult[]
  • imagingReports ImagingReport[]
  • timeline TimelineEvent[]
  • assessment? Assessment

Patient 1

patient.ts
  • initials string
  • age number
  • medicalHistory string[]

De-identified: no name. Built by the mapper (see below).

LabResult 0..n

results.ts
  • id string
  • testCode string
  • name string
  • value number
  • unit string

testCode is the key into the reference-range config.

ImagingReport 0..n

results.ts
  • id string
  • modality string
  • findings string
  • flaggedAbnormal boolean

Free text, so abnormality is flagged by the radiologist, not computed.

Assessment 0..1

assessment.ts
  • workingAssessment string
  • confidence ConfidenceLevel
  • nextAction NextAction
  • notes string
  • followUpDate? ISO date
  • savedAt ISO string

followUpDate only when next action is follow_up or refer.

TimelineEvent 0..n

timeline.ts
  • id string
  • type TimelineEventType
  • at ISO string
  • description string

toPatient(dto)

api/mappers/patient.mapper.ts

Pure function. Builds initials from first + last name and drops the full name, so it never reaches the UI, URLs or logs.
